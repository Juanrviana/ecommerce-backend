# 🛒 E-commerce Backend API

API robusta de backend desenvolvida para um sistema de comércio eletrónico, focada em boas práticas de arquitetura de software, consistência transacional e segurança.

## 🛠️ Tecnologias Utilizadas
* **Node.js** & **Express** (Criação do servidor e rotas REST)
* **PostgreSQL** (Base de dados relacional para consistência de dados e stock)
* **Dotenv** & **CORS** (Segurança e gestão de variáveis de ambiente)

## 📌 Funcionalidades Implementadas
* Estrutura de base de dados relacional completa (Utilizadores, Categorias, Produtos, Pedidos e Itens do Pedido).
* Endpoints para criação e gestão de categorias de produtos.
* Conexão segura ao PostgreSQL utilizando *connection pooling*.
